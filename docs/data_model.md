# Схема данных

## rooms — номера
| Поле | Тип | Ограничение |
|------|-----|-------------|
| room_id | строка | PK, уникальный, не пустой |
| price_per_night | decimal(10,2) | > 0, 2 знака |

## bookings — брони
| Поле | Тип | Ограничение |
|------|-----|-------------|
| booking_id | строка | PK, уникальный, не пустой |
| guest_name | строка | не пустая |
| room_id | строка | FK → rooms.room_id, существует |
| check_in | date (ISO ГГГГ-ММ-ДД) | корректная дата |
| check_out | date (ISO ГГГГ-ММ-ДД) | строго > check_in |
| status | enum | «активна» / «отменена» |
| price_per_night | decimal(10,2) | снимок цены на момент оформления |

## Связи
rooms (1) ──< bookings (N) по room_id

## Правила целостности
- booking_id уникален (в таблице и в файле импорта).
- room_id существует в rooms.
- check_out > check_in; заезд включается, выезд — нет.
- Активные брони одного номера не пересекаются.
- Отменённые не занимают номер.
- При ошибке импорта весь файл отклоняется.

## Производные (не хранятся)
- nights = (check_out - check_in).days
- cost = nights * price_per_night, округление до 2 знаков
