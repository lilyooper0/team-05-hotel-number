# Форматы данных (согласовано командой 5)

## Бронь (в памяти, CSV, XLSX)
| Поле | Тип | Обязательное | Пример |
|------|-----|--------------|--------|
| booking_id | строка, уникальная | да | B-001 |
| guest_name | непустая строка | да | Иванов Иван |
| room_id | строка, номер существует | да | 1 |
| check_in | ГГГГ-ММ-ДД | да | 2026-11-09 |
| check_out | ГГГГ-ММ-ДД, строго позже check_in | да | 2026-11-12 |
| status | «активна» или «отменена» | да | активна |
| price_per_night | число, 2 знака, > 0 | да | 1000.00 |

## CSV (импорт и хранение)
- Кодировка UTF-8, разделитель — запятая, первая строка — заголовки.
- Обязательные столбцы: все поля брони выше.
- Импорт «всё или ничего»: при любой ошибке файл отклоняется,
  состояние не меняется. Отчёт об ошибках — строка + причина.

## XLSX (выгрузка)
### Лист «Данные»
Все брони + расчётные столбцы `nights` и `cost`.

### Лист «Итоги»
Общие показатели: `active_count`, `cancelled_count`, `active_total`.
Разбивка по номерам (по каждому существующему номеру, сортировка по room_id):
`room_id`, `active_count`, `nights`, `total`.

- Если броней нет — создаются заголовки и нулевые общие показатели.
- Сумма `total` по строкам = `active_total`.
- Выгрузка не изменяет брони.
  
## Правила импорта CSV 
- Обязательные столбцы: booking_id, guest_name, room_id, check_in,
  check_out, status, price_per_night. Нет столбца — файл отклоняется.
- Номер строки в отчёте: заголовок = 1, первая строка данных = 2.
- Проверяется: уникальность booking_id (в таблице и файле),
  существование room_id, непустое guest_name, даты ISO и check_out>check_in,
  status ∈ {активна, отменена}, price_per_night > 0 и ≤2 знаков,
  пересечения активных броней с сохранёнными и между строками файла.
- Отчёт перечисляет ВСЕ ошибки (строка + причина).
- При любой ошибке: added = [], состояние не меняется.
